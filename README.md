# ProductOS

ProductOS — единое пространство управления товарными данными. Проект показывает, как объединять записи из разных источников, устранять расхождения и формировать единую карточку товара.

В репозитории находится интерактивный прототип на React, TypeScript и Vite.

## Возможности

- Обзор каталога и качества товарных данных.
- Поиск и фильтрация товаров по статусу, источнику и категории.
- Product Identity: сравнение трёх записей и выбор общих названия и категории.
- Объединение записей в master-карточку с сохранением исходных идентификаторов.
- Сохранение результата в браузере и сброс демонстрации.
- Адаптивный интерфейс для настольных и мобильных экранов.

## Запуск

Требуются Node.js 22.12+ и pnpm 11.19.0. Установить pnpm можно командой `npm install --global pnpm@11.19.0`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://127.0.0.1:5173. Для остановки сервера нажмите `Ctrl+C`.

В Windows можно запустить `start.cmd`: он установит зависимости при необходимости и откроет локальный сервер по тому же адресу.

## Сборка

```sh
pnpm build
pnpm preview
```

Команда сборки проверяет типы и создаёт статические файлы в `dist/`. Предпросмотр доступен по адресу http://127.0.0.1:4173. Для первой установки зависимостей требуется интернет.

## Сценарий

1. На главной нажмите «Разобрать конфликты».
2. В каталоге выберите «Проверить совпадение» для AURA Balance.
3. Сравните записи и выберите Master Name и Master Category.
4. Нажмите «Объединить в один товар», затем откройте итоговую карточку.

Кнопка сброса в верхней панели позволяет повторить сценарий. Результат хранится локально в браузере под ключом `productos-demo-v1`.

## Структура

```text
src/
  main.tsx             экраны, демонстрационные данные и состояние
  styles.css           стили и адаптивная вёрстка
index.html             точка входа и метаданные страницы
start.cmd              запуск в Windows
package.json           зависимости и команды
pnpm-lock.yaml         зафиксированные версии зависимостей
pnpm-workspace.yaml    настройки установки
tsconfig.json          настройки TypeScript
.gitignore             исключения для локальных и конфиденциальных файлов
```

## Данные и границы прототипа

В каталоге семь демонстрационных товаров. Общие показатели, статусы подключений и оценка совпадения 96% заданы для сценария. Прототип работает локально: серверная часть, авторизация, реальные подключения к системам и отправка товаров на маркетплейсы не реализованы. Разделы CRM и аналитики представлены информационными окнами.

Для запуска не нужны ключи или переменные окружения. Локальные настройки, файлы `.env`, ключи, зависимости и результаты сборки исключены из Git.
